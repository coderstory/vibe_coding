## 工作方式

- **GSD 流程驱动**: 使用 `/gsd-plan-phase`, `/gsd-execute-phase` 等 GSD 命令，不手动执行子步骤
- **简约指令**: 话少直接，如 "直接执行 phase 16"，不要求中间汇报
- **全自动偏好**: 倾向 "使用推荐值，自动执行当前里程碑直到全部完成"，减少交互次数
- **清理强迫症**: 完成工作后要求清理目录、删除多余文件再提交
- **主动记忆**: 反复要求 "记住我的偏好，写入 memory.md"（历史中出现 3 次）
- **先诊断再回滚**: build 失败时先诊断根因，不立即回滚
- **目录前置检查**: 执行命令前先确认当前目录是否正确
- **Windows 环境**: 注意 pwsh/bash 差异、中文路径编码、DNS 问题

## Git 规范

- **commit 语言**: 必须使用中文撰写 commit message
- **提交前清理**: 先删除多余/缓存文件再提交
- **目录确认**: 提交前确认在正确的项目目录中
- **记忆文件不提交**: `.claude/projects/` 下的 memory 文件不提交到 git

## 编辑规范

- **Edit 工具安全**: 使用最小唯一字符串作为 old_string，避免跨段落匹配导致误删
- **编辑前读文件**: 先读取完整文件，确认 old_string 精确匹配
- **不要跨段匹配**: 每段单独替换

## 反馈风格

- **简洁直接**: 不要总结做了什么，直接给结果
- **证据支撑**: 用命令输出验证，不空口说"完成"
- **问题即时报告**: 发现问题立即告知，不等到最后汇总
- **不主动汇报进度**: 只需在关键节点告知结果即可

## 测试与构建

- **编译优先**: Gradle 构建问题优先排查而非跳过测试
- **依赖问题**: 先检查版本对齐（Lombok/Spring AOP/Spring Boot）
- **中文路径**: Windows 中文路径需 `-Dfile.encoding=GBK`
- **localhost**: 使用 `127.0.0.1` 替代 `localhost` 避免 DNS 问题

## 沟通偏好

- 全程中文，无需解释为什么用中文
- 技术术语保留英文原文（如 RocketMQ、Gradle、Bean）
- 不主动使用 emoji
- 不问"是否要执行"，直接执行
