## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| migrate.js 字符串替换失败 | 使用 String.replace() 替换包声明时，~50% 文件未匹配成功 | advisory | 使用 fix-all.js 基于文件路径计算预期包名，而非字符串匹配 |
| 自动化脚本忽略 XML | fix-all.js 只处理 Java 文件，不做 XML 包引用更新 | blocking | MyBatis XML mapper 必须在 Java 迁移后手动检查并更新包引用 |
