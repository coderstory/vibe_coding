# Phase 34 Plan 01: 安全加固 + 页面状态打磨

## Requirements

| ID | Description | Type |
|----|-------------|------|
| HWM-21 | 非 ADMIN 角色用户无法访问硬件监控 API 端点，返回 403 | Backend |
| HWM-23 | 页面加载骨架态 / 空状态 / 错误状态 | Frontend |
| HWM-24 | SSE 断连重连顶部提示 | Frontend |

## Tasks

### Wave 1: Backend — API 权限控制 (TDD)

**T1: JWT 添加角色声明 + 过滤器解析角色** (RED→GREEN)
- `JwtTokenProvider.generateToken()` 添加 `role` claim（role_code）
- `AuthService.login()` 查 role 表获取 role_code 传入 generateToken
- `JwtAuthenticationFilter` 从 claims 解析 role，设置 ROLE_ADMIN 或 ROLE_USER

**T2: SecurityConfig 添加硬件 API 权限规则** (RED→GREEN)
- `.requestMatchers("/api/monitor/hardware/**").hasRole("ADMIN")`
- 测试：非 ADMIN token 访问返回 403

**Test files:** `JwtTokenProviderTest`, `SecurityConfigTest`

### Wave 2: Frontend — 页面状态处理 (TDD)

**T3: 加载骨架 + 空状态 + 错误状态**
- HardwareMonitorPage: `pageLoading` 初始连接态 → v-loading
- CpuGauge/MemoryGauge: `null` 数据时显示空状态
- DiskPartitions/SystemInfo: 已有空状态，确认保留
- Error banner: 从 composable `error` ref 驱动 el-alert

**T4: SSE 断连重连提示**
- 顶部横幅："正在重连，{n} 秒后重连..."
- `connected` 恢复时自动消失
- 颜色区分：断开黄色，连接绿色

**Test files:** `HardwareMonitorPage.test.ts`, `useHardwareMetrics.test.ts`（扩展）

### Wave 3: Verification

**T5:** 验证
- `./gradlew.bat test` 后端测试全部通过
- `npx vue-tsc --noEmit` 类型检查通过
- `npm run build` 构建通过
- `npx vitest run` 前端测试通过
