```java
// SSE 连接管理模式：ConcurrentHashMap<String, SseEmitter>, UUID key, onCompletion/onTimeout/onError 回调

public class SeckillSseService {
    private final Map<String, SseEmitter> emitters = new ConcurrentHashMap<>();
    
    public SseEmitter subscribe(String queueId, long timeout) {
        SseEmitter emitter = new SseEmitter(timeout);
        emitter.onCompletion(() -> emitters.remove(queueId));
        emitter.onTimeout(() -> emitters.remove(queueId));
        emitter.onError(e -> { log.warn("error: {}", e.getMessage()); emitters.remove(queueId); });
        emitters.put(queueId, emitter);
        try {
            emitter.send(SseEmitter.event().name("connected").data("..."));
        } catch (IOException e) { emitter.complete(); }
        return emitter;
    }
    
    public boolean sendToQueue(String queueId, String eventName, Object data) {
        SseEmitter emitter = emitters.get(queueId);
        try {
            emitter.send(SseEmitter.event().name(eventName).data(data));
            return true;
        } catch (IOException e) { emitters.remove(queueId); return false; }
    }
}
```

    在包 `cn.coderstory.springboot.sse.monitor` 下创建 `HardwareSseService` 类。实现广播模式的 SSE 推送服务，具体要求：

    1. **类注解：** `@Service @Slf4j @RequiredArgsConstructor`
    2. **连接池：** `private final Map<String, SseEmitter> emitters = new ConcurrentHashMap<>();` — UUID 作为连接标识（区别于 SeckillSseService 的 queueId）
    3. **`createEmitter()` 方法：**
       - 生成 UUID `clientId`
       - `new SseEmitter(0L)` — 永不超时（D-03：不额外发送心跳，数据推送自带心跳语义）
       - 注册 `onCompletion(() -> emitters.remove(clientId))`
       - 注册 `onTimeout(() -> emitters.remove(clientId))` — 60s 后自动清理（D-03：SseEmitter 自带 60s 超时在 spring-web 层，0L 表示禁用 SseEmitter 超时，具体超时由底层 Tomcat 连接超时控制。这里用 0L 让 SseEmitter 不主动超时，由 connection 层管理）
       - 注册 `onError(e -> { log.warn("SSE client {} error: {}", clientId, e.getMessage()); emitters.remove(clientId); })`
       - `emitters.put(clientId, emitter)`
       - 发送初始连接事件：`emitter.send(SseEmitter.event().name("connected").data("{\"status\":\"connected\"}"))`
       - 若发送失败调用 `emitter.complete()`
       - `log.debug("SSE connected: {} (total: {})", clientId, emitters.size())`
       - 返回 emitter
    4. **`broadcast(String eventName, Object data)` 方法：**
       - 如果 `emitters.isEmpty()` 直接 return，不遍历空池
       - `emitters.forEach((id, emitter) -> { ... })`
       - 内部调用 `emitter.send(SseEmitter.event().name(eventName).data(data, MediaType.APPLICATION_JSON))`
       - 捕获 `IOException` 时执行 `log.debug("SSE broadcast failed for {}: {}", id, e.getMessage())` + `emitters.remove(id)`
       - 不用 `@Async`（RESEARCH.md 反模式：客户端少时同步广播开销可忽略，`@Async` 引入线程调度延迟）
    5. **`getActiveConnectionCount()` 方法：** 返回 `emitters.size()`
    6. **`unsubscribe(String clientId)` 方法：** `emitters.remove(clientId)` 后调用 `emitter.complete()`
    7. **注释规范：** L3 级注释（类级 Javadoc + 方法级 Javadoc）
       - 类 Javadoc 说明广播模式、UUID 连接标识、ConcurrentHashMap 连接池
       - `createEmitter()` Javadoc 说明参数/返回值/回调注册
       - `broadcast()` Javadoc 说明遍历写入、IOException 自动移除
