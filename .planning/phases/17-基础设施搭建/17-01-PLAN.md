# Phase 17 Plan: 基础设施搭建

## 目标

集成前后端代码质量工具链，搭建重构安全网。为后续 Phase 18-21 的重构工作提供自动化的代码质量验证能力。

## 涉及需求

- TOOL-01: 配置 EditorConfig 统一编辑器设置
- TOOL-02: 升级 ESLint 到 10.x flat config + typescript-eslint + eslint-plugin-vue
- TOOL-03: 集成 @stylistic/eslint-plugin
- TOOL-04: 配置 Stylelint 17.x
- TOOL-05: 集成 ArchUnit 1.4.0
- TOOL-06: 集成 Checkstyle
- TOOL-07: 集成 PMD
- TOOL-08: 集成 SpotBugs 4.9.3
- TOOL-09: 集成 JaCoCo
- TOOL-10: 集成 Error Prone 2.37.0

## 任务分解

### Plan 1: 前端工具链

1. **EditorConfig** — 在项目根目录创建 `.editorconfig`，统一缩进(2 spaces)、换行符(LF)、编码(UTF-8)
2. **ESLint 10.x flat config 升级**
   - 安装最新依赖: `eslint@10`, `typescript-eslint`, `eslint-plugin-vue`, `@stylistic/eslint-plugin`, `globals`
   - 从 `.eslintrc.cjs` 迁移到 `eslint.config.js` (flat config)
   - 保留现有规则，扩展 typescript-eslint strict 和 stylistic 规则
3. **Stylelint 17.x**
   - 安装 `stylelint@17`, `stylelint-config-standard`
   - 在 `app-vue/` 下创建 `stylelint.config.js`
   - 配置对 `src/**/*.css` 的检查

### Plan 2: 后端工具链

1. **ArchUnit 1.4.0**
   - 添加 `com.tngtech.archunit:archunit-junit5:1.4.0` 依赖
   - 创建架构测试 `ArchitectureTest.java`，定义:
     - Controller 层不能直接依赖 Mapper 层
     - Service 层不能依赖 Controller 层
     - 包依赖方向规则(shared 层可被任何域依赖，域之间不能互相依赖)
2. **Checkstyle**
   - 添加 `build.gradle.kts` 配置 `checkstyle` 任务
   - 创建 `config/checkstyle/checkstyle.xml`，参考 Google 风格简化版
3. **PMD**
   - 添加 `build.gradle.kts` 配置 `pmd` 任务
   - 创建 `config/pmd/pmd-rules.xml`，启用基本规则集
4. **SpotBugs 4.9.3**
   - 添加 `com.github.spotbugs.snom:spotbugs:4.9.3` 插件
   - 配置 `build.gradle.kts` 启用 SpotBugs
5. **JaCoCo**
   - 添加 `build.gradle.kts` 配置 `jacoco` 插件
   - 配置 `./gradlew.bat test jacocoTestReport` 生成覆盖率报告
   - 设定覆盖率目标(行覆盖率≥60%，后续逐步提高)
6. **Error Prone 2.37.0**
   - 添加 `net.ltgt.gradle:gradle-errorprone-plugin` 插件
   - 配置 `build.gradle.kts` 在编译时启用 Error Prone 检查

### Plan 3: 验证

1. **前端验证**
   - `npm run lint` — ESLint + Stylelint 同步通过
   - `npx vue-tsc --noEmit` — Vue SFC 类型检查
   - `npm run build` — 构建无报错

2. **后端验证**
   - `./gradlew.bat check` — Checkstyle/PMD/SpotBugs 全部通过
   - `./gradlew.bat test` — 单元测试 + ArchUnit 架构测试通过
   - `./gradlew.bat test jacocoTestReport` — JaCoCo 报告生成

3. **集成验证**
   - `./gradlew.bat bootRun` — 应用正常启动
   - 前后端联调确认功能无回归

## 关键风险

1. **ESLint flat config 兼容性**: eslint-plugin-vue 和 typescript-eslint 可能不完全兼容 flat config。应对: 使用 `@typescript-eslint/eslint-plugin` v8 的 flat config 预设
2. **Gradle 插件版本兼容**: SpotBugs/Error Prone 可能与 JDK 26 不兼容。应对: 先在测试环境验证插件可用性，准备降级方案
3. **ArchUnit 规则过严**: 初始规则可能因现有代码违规而失败。应对: 先定义宽松规则，逐步收严

## 验证命令

```bash
# 前端
cd app-vue && npm run lint && npx vue-tsc --noEmit && npm run build

# 后端
cd springboot && ./gradlew.bat test check jacocoTestReport && ./gradlew.bat bootRun
```
