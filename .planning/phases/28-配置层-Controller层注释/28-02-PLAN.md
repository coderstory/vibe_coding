## 注释标准引用（Phase 27）

类级 Javadoc 模板：
```java
/**
 * 类职责说明（中文陈述句）。
 * <p>
 * 详细描述类或接口的核心功能（职责清晰可省略此段）。
 *
 * @since 1.7.0
 */
```

方法级 Javadoc 模板：
```java
/**
 * 方法说明（陈述句，说明做什么而非如何做）。
 *
 * @param paramName 参数说明
 * @return 返回值说明
 */
```

私有方法：行内注释即可（`// 说明`），不需要完整 Javadoc。

说明：
- 禁止 `@author` 标签
- `@since` 统一为 `1.7.0`（注释是 v1.7 添加的，不追溯原始创建版本）
- CRUD 方法使用简洁风格（D-05），复杂方法稍详细（D-06）
- 方法 Javadoc 用陈述句，说明做什么（D-08）
- 不允许空骨架注释（有标签无描述）
