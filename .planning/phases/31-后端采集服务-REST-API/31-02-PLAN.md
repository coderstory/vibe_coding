    **collect() 方法（D-08 统一 2s 主循环）:**
    ```java
    public void collect() {
        HardwareMetricsDTO snapshot = new HardwareMetricsDTO();
        snapshot.setTimestamp(System.currentTimeMillis());

        // CPU & 内存 — 每次采样
        snapshot.setCpu(sampleCpu());
        snapshot.setMemory(sampleMemory());

        // 系统信息 — 每次采样
        snapshot.setSystem(sampleSystem());

        // 磁盘 & 网络 — 每 diskNetInterval 次采样更新（默认每 3 次 = 6s）
        diskNetCounter++;
        if (diskNetCounter >= properties.getDiskNetInterval()) {
            diskNetCounter = 0;
            snapshot.setDisks(sampleDisks());
            snapshot.setNetwork(sampleNetwork());
        } else {
            // 非更新周期，复用缓存值（读锁保护）
            cacheLock.readLock().lock();
            try {
                if (currentMetrics != null) {
                    snapshot.setDisks(currentMetrics.getDisks());
                    snapshot.setNetwork(currentMetrics.getNetwork());
                }
            } finally {
                cacheLock.readLock().unlock();
            }
        }

        // 写入缓存（写锁）
        cacheLock.writeLock().lock();
        try {
            currentMetrics = snapshot;
            // 每 trendDecimation 次采样写入趋势（默认每 5 次 = 10s）
            trendCounter++;
            if (trendCounter >= properties.getTrendDecimation()) {
                trendCounter = 0;
                historyBuffer.add(snapshot);
            }
        } finally {
            cacheLock.writeLock().unlock();
        }
    }
    ```

    **sampleCpu()（RESEARCH Pattern 3，D-07）:**
    - try-catch 包裹，异常时 log.warn + return CpuMetricsDTO.empty()（D-12 降级）
    - 使用 getSystemCpuLoadTicks() + getSystemCpuLoadBetweenTicks(prev, current)
    - 缩放: `systemCpuPercent = systemLoad / logicalProcessorCount * 100`
    - 各核: `perCorePercent = perCoreLoad[i] * 100`
    - 四舍五入到一位小数: `Math.round(systemCpuPercent * 10.0) / 10.0`
    - 获取 ProcessorIdentifier 填充 processorName/frequency/cpu64bit
    - 注意: `prevCpuTicks` 在每次采样后更新为 current

    **sampleMemory()（HWM-03）:**
    - `GlobalMemory memory = hal.getMemory()`
    - total = memory.getTotal(), available = memory.getAvailable()
    - used = total - available
    - usagePercent = used * 100.0 / total
    - 所有值封装为 MetricValue（自动格式化: bytes→GB/MB，百分比→"xx.x%"）
    - 辅助方法: `MetricValue<Long> formatBytes(long bytes)` → 使用 `String.format()` 和 1024 进制除法（Bytes→KB→MB→GB→TB）
    - 辅助方法: `MetricValue<Double> formatPercent(double pct)` → 保留一位小数 + "%" 单位

    **sampleDisks()（RESEARCH Pattern 4，HWM-04, HWM-05）:**
    - `List<HWDiskStore> currentDisks = hal.getDiskStores()`
    - 遍历每个 disk，为每个 disk 创建 DiskMetricsDTO
    - 差分: 如果 prevDisks 有对应索引的 disk，计算 readBytesPerSec = (current - previous) * 1000 / intervalMs
    - 没有 prev 时 readBytesPerSec 等设为 null（首次采集无差分）
    - 更新 `prevDisks = currentDisks`
    - 每个 disk 的 size/totalSpace/usedSpace/usableSpace 使用 formatBytes()

    **sampleNetwork()（HWM-06）:**
    - `List<NetworkIF> currentNets = hal.getNetworkIFs()`
    - 对每个 net 调用 `net.updateAttributes()` 刷新
    - 遍历创建 NetworkMetricsDTO，差分计算 bytesSent/Recv 速率
    - 更新 prevNets

    **sampleSystem()（HWM-09）:**
    - `OperatingSystem os = hal.getOperatingSystem()`
    - osFamily = os.getFamily(), osVersion = os.getVersionInfo().toString()
    - osVersionInfo = os.getVersionInfo().getCodeName()
    - systemUptime = os.getSystemUptime()
    - processCount = os.getProcessCount()
    - systemUptimeFormatted = formatUptime(systemUptime) — 格式化为 "Xd Yh Zm"

    **Service 接口实现:**

    - `getTrendHistory()`: 读锁保护，返回 `historyBuffer.snapshot()`
