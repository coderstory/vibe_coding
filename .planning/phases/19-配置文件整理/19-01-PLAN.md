# Phase 19 Plan: 配置文件整理

## 目标

将 153 行的 `application.yaml` 按关注点拆分为 5 个独立配置文件，再通过 `spring.config.import` 组合加载，消除配置冗余，实现关注点分离。

## 涉及需求

- CONF-01: 拆分为 datasource/cache/mq/security/business 共 5 个独立配置文件
- CONF-02: spring.config.import 机制正确加载所有拆分文件
- CONF-03: 双 profile（默认 + test）启动验证
- CONF-04: 消除 application-test.yaml 中的重复配置

## 拆分方案

### 新文件结构

```
springboot/src/main/resources/
├── application.yaml              # 保留基础配置 + spring.config.import
├── application-datasource.yaml   # 数据源 + Flyway
├── application-cache.yaml        # Redis + Redisson
├── application-mq.yaml           # RocketMQ
├── application-security.yaml     # Security + JWT
└── application-business.yaml     # MyBatis Plus + Seckill + 日志
```

### 任务分解

1. **创建 application-datasource.yaml**
   - 移动: spring.datasource.*, spring.flyway.*
   - 保留完整注释

2. **创建 application-cache.yaml**
   - 移动: spring.data.redis.*, redisson.*

3. **创建 application-mq.yaml**
   - 移动: rocketmq.*

4. **创建 application-security.yaml**
   - 移动: security.*, jwt.*

5. **创建 application-business.yaml**
   - 移动: mybatis-plus.*, seckill.*, logging.*

6. **精简 application.yaml**
   - 保留: spring.application.name, spring.threads.virtual, spring.servlet.multipart, server.port
   - 添加 spring.config.import 指向 5 个拆分文件
   - 保留 server 和 logging 在原文件顶部（logging 也可放在 business 中，但作为常用配置留在主文件更方便）

7. **清理 application-test.yaml**
   - 检查并消除与主配置重复的内容

## 验证

```bash
cd springboot
./gradlew.bat bootRun              # 默认 profile 启动
# Ctrl+C 停止后:
./gradlew.bat bootRun --args='--spring.profiles.active=test'  # test profile 启动
```
