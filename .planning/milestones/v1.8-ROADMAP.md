# Milestone v1.8: Windows 硬件负载监控

**Status:** ✅ SHIPPED 2026-05-10
**Phases:** 31-34
**Total Plans:** 8

## Overview

Windows 系统硬件负载监控页面，实时展示 CPU/内存/磁盘/网络指标。通过 OSHI 7.x FFM 库采集硬件数据，REST API + SSE 推送至前端，ECharts 实时可视化。TDD 驱动开发，接口可 mock 设计。

## Phases

### Phase 31: 后端采集服务 + REST API

**Goal**: 后端集成 OSHI 7.x FFM 库，实现 CPU/内存/磁盘/网络指标的定时采集，提供 REST API 和环形缓冲区趋势查询
**Depends on**: v1.7 产物（Phase 30 注释维护机制建立完成后代码基线稳定）
**Plans**: 3 plans

Plans:

- [x] 31-01: 基础层 — OSHI 依赖、DTO 定义、RingBuffer、Service 接口、配置类
- [x] 31-02: 采集实现 — HardwareMetricsServiceImpl + 单元测试
- [x] 31-03: REST API — 3 端点（current/trend/system）+ Controller 测试 + 集成测试

### Phase 32: SSE 实时推送 + 前端基础页面

**Goal**: 后端通过 SSE 实时推送硬件指标，前端展示 CPU/内存仪表盘、磁盘容量和系统信息
**Depends on**: Phase 31（SSE 推送需要采集服务提供数据）
**Plans**: 3 plans

Plans:

- [x] 32-01: 后端 SSE 广播服务 + Controller 端点 + 测试
- [x] 32-02: 前端类型定义 + SSE composable + 单元测试
- [x] 32-03: 前端页面（左导航/ECharts 环形图/磁盘进度条/系统信息）

### Phase 33: 完整图表 + 趋势

**Goal**: 磁盘 IO/网络吞吐量实时折线图、近 1 小时趋势图，图表组件适配海滩风主题
**Depends on**: Phase 32（图表数据来自 SSE 推送）
**Plans**: 1 plan

Plans:

- [x] 33-01: 完整图表（磁盘 IO/网络实时折线图 + CPU/内存趋势图）+ TDD + 页面集成

### Phase 34: 安全加固 + 打磨

**Goal**: 硬件监控 API 权限控制、页面加载/异常/断连状态处理
**Depends on**: Phase 32（状态处理在页面基础上打磨）
**Plans**: 1 plan

Plans:

- [x] 34-01: JWT 角色声明 + SecurityConfig 权限 + 前端骨架/错误/断连状态
